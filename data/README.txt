Project: Credit Risk Exploratory Data Analysis & Data Quality Audit with Python

Dataset name: Give Me Some Credit
Source: Kaggle competition — Give Me Some Credit
Official data page: https://www.kaggle.com/c/GiveMeSomeCredit/data

Files:
1. cs-training.csv — Main labelled dataset for exploratory analysis.
2. Data Dictionary.xls — Supporting documentation for dataset variables.

Purpose:
To practise data inspection, data-quality auditing, descriptive statistics, delinquency segmentation and visualisation using Python, Pandas and NumPy.

Important considerations:
- The dataset is for educational and portfolio analysis.
- Review the data dictionary before interpreting variables.
- Investigate missing, unusual and potentially invalid values.
- Do not assume correlation establishes causation.
- Findings from this dataset do not automatically represent current lending portfolios or predict the performance of a real lender.
- Keep the original source files unchanged.
- Do not publish the raw dataset to GitHub unless redistribution is permitted by the applicable source terms.
